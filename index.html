👋 Grown-Ups Corner

Comet Catch is a 75-second arcade catching game for roughly ages 6–10. The game is paused while this menu is open — press Q again to jump straight back in.

🎮 Controls (keyboard only — no mouse)

←→
Run left and right along the island
SPACE
Jump to reach high comets  ·  also starts & restarts a round
↑
Jump (same as Space)  ·  moves up in this menu
↓

Q
Open / close this menu (pauses & resumes the game)

🎯 The goal

Comets are launched from three flower cannons. Bloop carries a basket — run underneath and let them drop in. Catching in a row builds a streak that multiplies points, and every 450 points the sky changes to a brand new time of day.

🌈 Rainbow orb = slow motion + big points  ·  💗 Bouncy berry = bounces once, catch the rebound  ·  ⭐ Gold comet = fast and flat  ·  😤 Sneezy cloud = the one thing to dodge.

🧠 Skills this builds

Trajectory predictionAnticipation timing Spatial awarenessReaction time Response inhibitionVisual pattern recognition Motor planningSustained attention
  • Trajectory prediction & interception. The heart of the game: read a curved flight path early, decide where it will land, and get there first. This "coincidence–anticipation timing" is the same skill used to catch a ball.
  • The fading helper ring. Beginners get a bright ring on the ground showing the landing spot. As the child's catch rate climbs, the ring quietly shrinks and fades away — the scaffolding is removed exactly as fast as they stop needing it, so they learn to predict with their own eyes.
  • Response inhibition. Sneezy clouds must be actively avoided. Stopping a movement you already started is a core executive-function skill.
  • Second-order prediction. Bouncy berries must be caught after a rebound — the child predicts a path that changes mid-flight.
  • Pattern recognition. Each comet type telegraphs itself with a colour and a launch sound, so children learn to plan before the comet even leaves the cannon.

📈 It adapts. The game tracks the last 12 comets and keeps a rolling skill estimate. Speed, spawn rate, travel distance and helper-ring strength all follow it, so the game stays in the "just hard enough" zone for this particular child.

💜 Designed to be kind

There is no "Game Over", no lives, and no red X. A missed comet turns into a puff of sparkles and the very next catch pays a Bounce Back bonus. Rounds are 75 seconds by default so it is easy to say "one more go, then we stop".
